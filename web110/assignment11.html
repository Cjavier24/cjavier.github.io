What I Learned

In this assignment, I learned how to add images and multimedia to a web page. The first activity consisted of creating a raster image. Raster images are made of small squares called pixels, like a photo, so they can look blurry when you enlarge them. I created mine in ibisPaint, a drawing app, and saved it as a PNG file. The second activity was about vector graphics. Unlike raster images, vector images are made of shapes and lines that are described with math, so they stay sharp at any size. I created a simple vector image on Inkscape and saved it as an SVG file, which is actually just text that the browser draws. For the last activity, I added everything to this page. I used img tags for both images and added alt text to each one so screen readers can describe them to people who can't see them. Then I used the audio and video tags with several source files, like MP3 and OGA for the audio, and WebM, OGV, and MP4 for the video. I learned that not all browsers support the same formats, so giving more than one option makes sure the media plays for everyone. I also used an iframe to embed a YouTube video, which lets me show a video from another website without uploading it myself. After that, I used the W3C validator to make sure my page had no errors. As an aspiring web designer, I will use these skills all the time. I can use vector images for logos and icons because they look good on any screen, and raster images for photos. Accessibility is very important to me, so I will always add alt text to my images and controls to my audio and video, so every user can enjoy the content.
