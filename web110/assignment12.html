What I Learned

JavaScript is the language that makes web pages interactive, and as an aspiring web designer, I knew I had to learn it sooner or later. First of all, I was surprised to find out that JavaScript and Java are completely different languages, even though their names are so similar. I even had to double-check a quiz question about it! Second, I practiced with the code examples from the page. I used getElementById() to show my name on the page and Date() to display the current date. At first, my name kept disappearing because the second line of code replaced the first one, but after putting each one in its own element, everything worked. Mistakes like this one honestly help me understand how the code actually works. I also learned that JavaScript works with the DOM to do things like animate elements, create games, or check forms before sending them. Finally, the security section caught my attention, especially the part about never putting passwords inside scripts, since anybody can see the code. In summary, JavaScript will be very useful for my career. A website that looks nice is great, but a website that also responds to the user is even better, right?
