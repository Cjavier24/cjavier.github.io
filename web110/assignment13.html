These are the single-table SELECT statements I used in the W3Schools SQL TryIt Editor:

  • SELECT * FROM CUSTOMERS;
  • SELECT CustomerID, CustomerName FROM CUSTOMERS;
  • SELECT CustomerName, Address, City, PostalCode FROM CUSTOMERS WHERE Country = 'UK';
  • SELECT ContactName, CustomerName FROM CUSTOMERS ORDER BY ContactName;
  • SELECT COUNT(*) FROM CUSTOMERS;
  • SELECT Country, COUNT(*) FROM CUSTOMERS GROUP BY Country;
  • SELECT Country, COUNT(*) FROM CUSTOMERS GROUP BY Country ORDER BY COUNT(*) DESC, Country;
  • SELECT Country, COUNT(*) FROM CUSTOMERS GROUP BY Country HAVING COUNT(*) > 10 ORDER BY COUNT(*) DESC, Country;

These are the INSERT, UPDATE, and DELETE statements I used in the W3Schools SQL TryIt Editor:

In these activities, I learned that a database is an organized collection of data, and SQL is the standard language used to work with relational databases. I used SELECT to get data from a table, WHERE to filter rows, ORDER BY to sort the results, and COUNT, GROUP BY, and HAVING to count and group records. I also used INSERT, UPDATE, and DELETE to add, change, and remove data. As a future web designer, I can use this learning because many websites keep their information in databases like MySQL, so knowing basic SQL will help me understand and work with the data behind a website.
