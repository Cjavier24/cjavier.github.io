CSS (Cascading Style Sheets) is the language used to change how a web page looks. As an aspiring web designer, I wanted to learn this language because it will be essential for my career.

The first activity consisted of reading a tutorial about CSS. I'm already familiar with some of these CSS rules because they remind me of Lua, a language that I worked with a couple of months ago. However, the syntax is different, so this tutorial helped me finally understand how to write CSS correctly. I also learned that there are three ways to add CSS to a web page: inline, internal, and external.

For the second and third activities, I used inline and internal CSS on this page. Inline CSS goes inside an HTML tag with the style attribute, and internal CSS goes inside a style tag in the head of the page. I used internal CSS to make the heading bigger, and inline CSS to make this first paragraph italic. This helped me understand the "cascading" part of CSS: inline CSS wins over the other two, and on this page the internal CSS wins over the external file.

The fourth activity was about external CSS. I created a file called style.css with rules for the body, the heading, and the paragraphs, using properties like color, background-color, text-align, font-size, width, margin, and padding. Then I linked it to all my WEB110 pages, so now all of them share the same design. I really liked this part because I can change the look of every page by editing only one file.

After that, I used the W3C validators to check my HTML and stylesheet. Then I committed my changes in Visual Studio Code and synced them to GitHub.

In summary, I will use CSS all the time as a web designer. Accessibility is very important to me, and with CSS I can choose colors that are easy to read and make the text bigger for people who need it. In the future, I will use external stylesheets so my websites' design stays consistent and easy to update.
